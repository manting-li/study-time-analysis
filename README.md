# 项目目的

本项目演示一个完整且规模适中的数据分析流程：

1. 从 CSV 文件读取学生学习数据；
2. 检查数据的列、缺失值、重复值和合理范围；
3. 计算描述性统计量；
4. 计算学习时间与考试成绩的 Pearson 相关系数；
5. 用散点图展示两者关系；
6. 建立一元线性回归模型；
7. 使用决定系数 R² 评价模型，并给出结论。

# 数据说明

`data.csv` 包含 40 名虚拟学生的记录，每一行代表一名学生。

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| `student_id` | 学生编号 | 无 |
| `study_hours_per_week` | 每周平均学习时间 | 小时 |
| `sleep_hours_per_day` | 每天平均睡眠时间 | 小时 |
| `attendance_percent` | 课程出勤率 | % |
| `exam_score` | 考试成绩 | 分（满分 100）
分析方法

# 描述性统计

Notebook 使用 `describe()` 输出数值变量的样本数、均值、标准差、最小值、四分位数与最大值，以快速了解数据分布。

# 相关性分析

项目计算 `study_hours_per_week` 与 `exam_score` 的 Pearson 相关系数。该系数接近 1 表示强正线性关系，接近 -1 表示强负线性关系，接近 0 表示没有明显线性关系。

# 线性回归

模型形式为：

```text
考试成绩 = 截距 + 系数 × 每周学习时间
```

使用 `scikit-learn` 的 `LinearRegression` 进行拟合。Notebook 同时输出斜率、截距、预测成绩和 R²。R² 越接近 1，表示在这份数据中学习时间能够解释的成绩波动比例越高。

# 结果概述

在这份教学数据中，学习时间与考试成绩呈明显正相关（Pearson `r ≈ 0.985`）。拟合的一元线性回归线向上倾斜，模型的 `R² ≈ 0.971`，说明学习时间在这份数据中可以解释约 97.1% 的成绩差异。回归方程约为：

text
考试成绩 = 50.80 + 3.06 × 每周学习时间


这只是描述样本中变量之间的关系，不能据此断言“增加学习时间一定会导致成绩提高”。睡眠、出勤、基础水平、学习方法等因素同样可能影响考试成绩。
